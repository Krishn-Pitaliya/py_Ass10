# Python Assignment 10 - Web Scraping

## Overview
This repository contains my **Python Assignment 10**, which demonstrates web scraping using **Python**, **Requests**, and **BeautifulSoup4**.

The program scrapes product information from the **Books to Scrape** website, downloads product images, and compares product prices with a predefined target price.

## Features
- Extract product title
- Extract product price
- Extract product image URL
- Download product images
- Compare product prices
- Process multiple product URLs

## Technologies Used
- Python 3
- Requests
- BeautifulSoup4 (bs4)

## Installation

Clone the repository:

```bash
git clone https://github.com/<your-username>/py_Ass10.git
```

Install the required packages:

```bash
pip install requests beautifulsoup4
```

## Run

```bash
python web_scraper.py
```
